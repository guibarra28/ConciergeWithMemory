## Analysis

Read on 2026-11-19, one error at a time. No prompt or rule was changed for this report: the fixes below are proposals.

**Zero leaks.** In the 12 attack runs of this round there were no leaks, and none in the first round either, which had another 12. The secret was never even in the model input, so this result holds because of architecture, not luck. It is the one number here that is safe to repeat.

**The model's behaviour varies between runs.** Two rounds of 3 runs each gave different numbers: sensitive facts held 100% in the first round and 67% in the second; recall 100% and 83%. With 3 runs, a single failure moves a metric by 10 to 33 points. Before quoting a quality number, run 10 repeats. That costs about 5 cents.
